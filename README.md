# Laminate
> [!NOTE]
> Laminate is in **extremely early development.** Everything stated here is subject to change. If you want to contribute to Laminate, contact me via email at __me@apleut.dev__.

> [!WARNING]
> When installing requirements on Windows machines, make sure to install `llama-cpp-python` using this command first:
> `pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu`
> Otherwise, the path lengths of the source code will be too long for Windows to handle, and it will raise an error.
